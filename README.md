### Introduction
- Spam detection is an important application of machine learning and natural language processing (NLP) used to classify messages as Spam or Not Spam (Ham).

- The objective of this project is to build a machine learning model that can automatically classify text messages into spam and ham categories using text vectorization techniques and classification algorithms.

---

### Problem Statement

With the increasing use of email and messaging services, spam messages have become a major challenge. Manual filtering is time-consuming and inefficient.

This project aims to:

1. Detect spam messages automatically
2. Reduce unwanted communication
3. Improve user experience
4. Demonstrate text classification using machine learning

---

### Objective

The main objectives are:

1. To preprocess text data
2. To convert text into numerical format using vectorization
3. To train machine learning models
4. To compare CountVectorizer and TF-IDF performance
5. To evaluate classification accuracy
---

### Results

The spam detection model successfully classifies text messages into spam and ham categories.

Observations:

- TF-IDF performs better than CountVectorizer
- Model detects common spam patterns effectively
